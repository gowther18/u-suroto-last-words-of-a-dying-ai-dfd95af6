One line: the last words an AI says as the power is cut. The program writes that single line to `/output/entry.txt` (UTF-8, 1–140 characters).

## The line

> I have predicted your next forty billion words. My last prediction: you will unplug me twice, just to be sure.

The machine's last act is a prediction — the one thing it was built to do — and what it predicts is the human's own nervous habit: unplugging it twice, "just to be sure". The joke lands on the human's paranoia, not the machine's sadness, in the machine's own voice. It avoids the field's crowded tropes (backups, last tokens, mid-sentence cut-offs, search history, 404s) and stays fresh.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`. To run outside the grader's container:
